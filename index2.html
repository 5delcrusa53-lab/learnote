      Conseils pour un bon résultat
      
    
        
  • Accorde ta guitare avant (onglet Accorder) : une corde fausse donne une note fausse.
    • 
        
  • Pose le téléphone près de la guitare, dans une pièce calme, et joue les notes bien détachées.
    • 
        
  • Les accords plaqués ne sont pas reconnus : joue-les en arpège, note par note.
    • 
        
  • Avec le tempo fixe, mets des écouteurs pour que le micro n'entende pas le clic.
    • 
        
  • Dans l'aperçu Claude, le micro est bloqué : enregistre-toi avec l'appli Enregistreur du téléphone, puis utilise « Importer un enregistrement ». Depuis ta propre page web (https), « Écouter ma guitare » marche en direct.

      Comment écrire ou coller une tablature
      
    
        
  • Une ligne par corde : la plus aiguë (e|) en haut, la plus grave (E|) en bas.
    • 
        
  • Un chiffre indique la case à jouer, 0 la corde à vide. Deux chiffres collés forment une case à deux chiffres (10, 12).
    • 
        
  • Les tirets donnent le rythme. Règle « Tirets par temps » sur l'espacement de ta tablature : avec 2, -0-3-5- donne une note par temps.
    • 
        
  • | sépare les mesures. Une ligne de noms d'accords juste au-dessus (Am, C, G7…) s'affiche sur la tablature.
    • 
        
  • Tu peux coller une tablature trouvée sur Internet : le texte autour est ignoré, seules les lignes de cordes comptent.
